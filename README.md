# (working title) Photo Safety

Make a photo or video safe to share, in one step, fully offline: remove everything that can reveal where, when and
with which device it was taken, and mask faces and licence plates.

Status: planning. The name, scope and stack are not decided yet; see `docs/BRIEF.md` and `docs/RESEARCH.md`.
