# Reporting a security problem

Pakkon is used by people whose safety can depend on a file. If you find a way that a file cleaned by Pakkon still
reveals something, that the app sends anything off the device, or any other security problem, please report it
privately through GitHub: **Security → Report a vulnerability** on this repository. Please do not open a public
issue for it.

Include the steps to reproduce it and, if you can, a test file with fake data (never send real people's photos).

What Pakkon removes, what it cannot hide, and how it is tested: [`docs/SECURITY.md`](docs/SECURITY.md).
